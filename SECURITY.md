# Segurança e privacidade

Não envie ao repositório amostras reais de voz, consentimentos, perfis, credenciais, modelos ou caches.

Use somente voz própria ou expressamente autorizada. O projeto não deve ser usado para fraude, personificação enganosa, autenticação por voz ou fabricação de declarações.

Relate vulnerabilidades de forma privada ao mantenedor, evitando abrir detalhes exploráveis em uma issue pública.
