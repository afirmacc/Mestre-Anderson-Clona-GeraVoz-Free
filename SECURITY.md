# Política de segurança

## Versões suportadas

O projeto está em pré-alpha. Nenhuma versão é considerada pronta para produção.

## Como relatar

Não publique uma vulnerabilidade explorável em issue pública. Entre em contato de forma privada com o mantenedor do repositório e informe:

- versão ou commit;
- plataforma;
- impacto;
- passos mínimos para reprodução;
- mitigação conhecida, se houver.

Não envie credenciais, amostras reais de voz ou dados de terceiros no relatório.

## Dados proibidos no repositório

- áudio real;
- consentimentos e perfis;
- credenciais, tokens e chaves;
- modelos e caches;
- relatórios que identifiquem uma pessoa;
- caminhos privados da máquina.

## Uso responsável

Use somente voz própria ou expressamente autorizada. O projeto não deve ser usado para fraude, personificação enganosa, autenticação por voz, evasão de controles ou fabricação de declarações.

## Resposta esperada

O mantenedor buscará confirmar o recebimento, avaliar o impacto, preparar correção e divulgar o problema somente quando houver mitigação segura.
