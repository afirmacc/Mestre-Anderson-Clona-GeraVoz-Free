# Como contribuir

O projeto está em pré-lançamento. Antes de enviar uma contribuição:

1. não inclua voz real ou dado pessoal;
2. descreva plataforma e hardware testados;
3. adicione testes para mudanças de comportamento;
4. mantenha instalação idempotente;
5. não introduza fallback silencioso;
6. documente limitações e falhas conhecidas.
